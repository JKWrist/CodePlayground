# CodePlayground

多语言代码练习场，记录日常学习中的各类代码实验与调试片段。

## 目录结构

```
.
├── test_cmake/      # CMake 构建系统练习
├── test_cpp/        # C/C++ 语言特性与算法练习
├── test_gdb/        # GDB 调试技术与技巧
├── test_js_html/    # JavaScript / HTML 前端练习
├── test_kernel/     # Linux 内核相关实验
├── test_makefile/   # Makefile 编写练习
├── test_python/     # Python 脚本练习
├── test_shell/      # Shell 脚本练习
├── debug_code/      # 日常问题调试记录
└── *.sh             # Git 操作辅助脚本
```

## 简介

本仓库为个人编码练习仓库，涵盖以下方向：

- **C/C++**：语言基础、数据结构、算法实现
- **脚本语言**：Shell、Python 等自动化与工具脚本
- **构建系统**：Makefile、CMake 等构建流程配置
- **前端实验**：JavaScript 与 HTML 交互效果
- **调试技术**：GDB 调试段错误、内存泄漏等问题
